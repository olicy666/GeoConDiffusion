# GeoConDiffusion

This repository hosts the project page for **GeoConDiffusion: Inference-Time Geometry-Constrained Sampling for Video-Diffusion Novel View Synthesis**.

GeoConDiffusion is an inference-time sampling strategy for video-diffusion-based novel view synthesis. It uses coarse geometry as uncertain validity evidence to stabilize low-frequency scene layout and suppress geometrically invalid cross-view information propagation during denoising.
